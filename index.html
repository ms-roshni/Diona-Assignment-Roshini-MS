Dynamic Document Generators

Two data-driven, print-accurate HTML/CSS/JS reproductions of the supplied PDFs.

1. Medical & Travel Expense Request

Recreates Medical and Travel Expense Request.pdf: a claim form with six repeatable expense tables (prescriptions, over-the-counter drugs, supplies, parking, mileage, bus/taxi fare), a header with logo/claim number, a footer with Worker App ID and live page numbers, and automatic re-pagination as rows are added or removed.

2. Worker Progress Report

Recreates Worker Progress Report.pdf: a multi-section status form (return-to-work status, recovery, pain scale, treatment, medication, exercises, certification) driven by exclusive selections and free-text answers, with the same shared header/footer/pagination system.

Open generator →

How this was built

  • Both apps share /shared: a pagination engine that measures real rendered block heights and lays them out across US-Letter "paper" pages, a footer/header component builder, and small DOM helpers.
  • Each app's left panel edits a plain JS state object; every change re-runs the same render function used to build the initial page, so the document and the pagination always reflect the current data — including how many pages are needed.
